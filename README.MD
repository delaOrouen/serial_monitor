Usage

1. Install Python 3.13 using any means necessary. On windows, download from python.org.
2. verify Python is installed by running the following command from the terminal (such as Powershell). If
   you are using windows, you may need to reboot for this command to start working.

```
python --version
```

3. Install the dependancies by navigating to the directory that you downloaded the "visualizer" and run the following 
   command.
   ```
pip install -r requirements.txt
   ```
4. In windows, run the visualzier with the following command.
```
python ./visualizer.py
```
